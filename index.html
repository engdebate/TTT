把 ChatGPT 畫布變成 GitHub Page

從 ChatGPT 畫布產生網頁程式碼，整理成 GitHub Pages 可讀取的檔案結構，最後發布成可分享的網站。

檔案結構 發布步驟 常見提醒

一、需要準備哪些檔案？

GitHub Pages 最基本的靜態網站通常會包含以下檔案。首頁檔案一定要命名為 index.html。

📁 my-github-page/
├── index.html
├── style.css
├── script.js
└── 📁 images/

index.html

網站的主要內容與頁面架構。

style.css

網站的顏色、字體、排版與視覺設計。

script.js

網站的按鈕、互動與 JavaScript 功能。

images/

放置網站圖片，例如截圖、流程圖或插圖。

二、從 ChatGPT 畫布到 GitHub Pages

1. 在 ChatGPT 畫布建立網頁

請 ChatGPT 產生單頁網站，確認內容、排版與互動功能。

2. 整理成網站檔案

HTML 放進 index.html，CSS 放進 style.css，JavaScript 放進 script.js。

3. 建立 GitHub Repository

到 GitHub 建立新的 repository，並把所有檔案上傳到根目錄。

4. 啟用 GitHub Pages

進入 Settings → Pages，選擇 main branch 和 /root。

5. 開啟網站網址

完成後會得到類似 https://你的帳號.github.io/repository名稱/ 的網址。

三、常見提醒

檔名要正確

首頁一定要叫 index.html，大小寫也要一致。

路徑要正確

CSS 與 JS 的連結路徑必須和實際檔名相同。

圖片要一起上傳

若 HTML 使用 images/photo.png，GitHub 也要有同樣的資料夾與圖片。
